## Read before working in these areas

Read the matching file before changing anything it covers:

- Stores, services, types, backup export → `.kiro/steering/state-and-storage.md`
- Capacitor plugins, platform APIs, hooks, PWA/build config, `ios/`, `android/` → `.kiro/steering/native-and-pwa.md`
- Components or styling (`src/components/**`, `src/index.css`) → `.kiro/steering/ui-design.md`
- Writing or changing tests → `.kiro/steering/testing.md`
- Cloud sync, auth, `supabase/schema.sql` → `.kiro/steering/supabase.md`
- Branches, commits, PRs → `.kiro/steering/git-workflow.md`
